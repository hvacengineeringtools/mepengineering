Adds up the pressure loss along one air path, from the fan to the furthest outlet. Each section is a length of straight duct, a fitting (elbow, transition or tap), or an item of equipment with a pressure drop from the maker’s data. Straight duct uses the same equivalent-diameter and Altshul–Tsal friction as sheet XV. For elbows, transitions and taps the loss coefficient C is read from the duct-fitting tables once you give the sizes, angle and flow; you can type your own C instead. The running total is kept as you go, and the table can be downloaded as an Excel workbook that recalculates, or printed for submission.

2. Sections along the index run

Add the sections in the order the air flows. A straight duct has a flow, a size and a length. A fitting takes its loss from the velocity at the size you give: enter the fitting’s own size and flow, then the angle or the second size it needs, and the coefficient C appears. Add equipment (coil, filter, attenuator, damper, grille) where it sits, with the pressure drop from the maker’s data at the design flow.

Notes and formulae

The working for the section you last changed, with the values now on the sheet.

1. Air

ρ = 101325 / (287.05 T), μ = 1.458×10⁻⁶ T1.5 / (T + 110.4), ν = μ / ρ, with T in kelvin

2. Straight duct

Rectangular a × b: De = 1.265 ((a b)³ / (a + b))0.2
Round: De = D
ve = Q / (π De² / 4), Re = ve De / ν
f′ = 0.11 (ε / De + 68 / Re)0.25; f = f′ if f′ ≥ 0.018, otherwise 0.85 f′ + 0.0028
Δp per metre = (f / De) × ½ ρ ve²
Duct loss = Δp per metre × length

3. Fittings

Fitting loss = C × ½ ρ v², with v = Q / (area of the reference section), the actual duct area, not the equivalent circle.
Elbow and other fitting: the duct size you give.
Transition: the smaller end.
Tap: the common section, which is the main before the tap in supply air, and the main after the tap in return air.

4. Coefficients C

Smooth rectangular elbow: C = C₀(r/W, H/W) × angle factor(θ)
Mitered elbow: C(θ, H/W) from the table, or a constant if it has turning vanes
Round smooth elbow: C = C₀(r/D) × angle factor(θ)
Transition: C(area ratio, included angle θ), θ = 2 atan((Δ / 2) / L), the larger of the width and the depth
Tap: C of the branch and C of the straight-through path, each by area ratio and flow ratio
Linear interpolation in the table; beyond the edge of the table the end value is used and the section is flagged.

5. Equipment and totals

Equipment: the pressure drop in Pa as entered.
Section = duct + fitting + equipment
Running total = sum of the sections down to this one
Design total = total × (1 + margin)

Limits used for the flags

Maximum velocity by duct type, from our reference data: riser 7.5 m/s, branch 7.5, zone 5.5, flex 2.5, branch FOH 5.5, zone FOH 3.5. The friction flag is the figure in section 1 (0.8 Pa/m from our reference data). A flag does not stop the section being counted.

Roughness

Elbow table C₀ (smooth rectangular, r/W across, H/W down)

Angle factors

The other tables (transitions, taps, mitered and round elbows) follow the same layout and are read in the same way.

How this sheet works

  • One card per duct, fitting or equipment item, with the running total and a design margin. The friction formula is the same as sheet XV.
  • The workbook this sheet writes uses ordinary formulas, so it opens and recalculates without macros.
  • Where a fitting’s coefficient C is typed, it replaces the table value, and the card says so.

How the fitting coefficients were checked

I put 51 test fittings through the fitting calculation of our duct template and through this sheet, and compared the coefficient C each gave. 39 are identical. 12 differ, and in all 12 the template is the one that is wrong. This sheet uses the correct value.

The tables are the ASHRAE duct-fitting tables as laid out in the template. Confirm the coefficients you rely on against the ASHRAE Duct Fitting Database.

Reference velocity

The velocity pressure used for transitions (the smaller end) and for taps (the common section) follows the usual convention of the fitting database. Check it against the table you are quoting. If your design guide refers C to another section, type the C that matches.

What is not included

Fan and system effect, air leakage, insulation and liner, dampers and grilles not entered as equipment, and the change in static regain across a tap.
